# Cafe Order + POS คาเฟ่ (หลายร้าน)

| เส้นทาง | คืออะไร |
|---|---|
| `/indexpos` (`indexpos/index.html`) | หน้าแรก Easy POS (landing) |
| `/` (`index.html`) | ส่งต่อไป `/indexpos` · ลิงก์เดิมที่มี `?t=` `?o=` ส่งต่อไป `/order` |
| `/s/<รหัสร้าน>` (`order/index.html`) | หน้าสั่งอาหารของลูกค้าแต่ละร้าน (`/order` เฉย ๆ ใช้ร้านแรก) |
| `/retail` | Easy POS Retail: เข้าสู่ระบบของร้านค้า แล้วเปิด POS ร้านค้า (ผู้จัดการ/พนักงานเห็นเฉพาะร้านตัวเอง) |
| `/pos` | POS ของร้าน ต้องเข้าสู่ระบบ ผู้จัดการ/พนักงานเห็นเฉพาะร้านตัวเอง |
| `/admin` | แดชบอร์ดผู้ดูแลระบบ (ทั้ง Cafe และ Retail): สร้างร้าน กำหนดผู้จัดการ/โควตาพนักงาน ค่าบริการรายเดือน ตรวจสลิป |

## โครงสร้างข้อมูล (Supabase)

- `pos_shops` ร้านค้า (รหัสร้าน ระบบ `product` = cafe/retail ราคา/เดือน โควตาพนักงาน วันหมดอายุ สถานะ)
- `pos_members` บัญชีในร้าน (ผู้จัดการ 1 คน + พนักงานตามโควตา) หนึ่งอีเมลอยู่ได้ร้านเดียว
- `pos_data` ข้อมูล POS แยกตาม `shop_id` (เมนู โต๊ะ ออเดอร์ ตั้งค่า) อัปเดตเรียลไทม์
- `cafe.shop_state` / `cafe.orders` เมนูและออเดอร์จากแอปลูกค้า แยกตามร้าน
- `pos_payments` การแจ้งชำระค่าบริการ (สลิปอยู่ใน bucket ส่วนตัว `pos-slips`)
- `pos_admins`, `pos_platform` ผู้ดูแลระบบและบัญชีรับค่าบริการ
- สิทธิ์ทั้งหมดบังคับด้วย RLS: ร้านอ่าน/เขียนได้เฉพาะ `shop_id` ของตัวเอง ร้านที่หมดอายุเกินช่วงผ่อนผันหรือถูกระงับจะเขียนข้อมูลไม่ได้
- ตารางเดิม `pos_docs`, `pos_staff`, `cafe.state` เก็บไว้เป็นสำเนา อ่านได้เฉพาะผู้ดูแลระบบ

SQL ของการย้ายเป็นหลายร้านอยู่ที่ `supabase/migrations/pos_multi_shop.sql`

## แก้ไข POS

ซอร์สหลักคือ `src/cafe-pos.artifact.html` แล้วสร้างเวอร์ชันเว็บด้วย

```
python3 tools/build_pos.py
```

ซึ่งจะเขียน `pos/index.html` โดยเพิ่มระบบล็อกอิน ฐานข้อมูลรายร้าน และหน้าค่าบริการจาก `tools/standalone-shim.html`

## แก้ไข POS ร้านค้า (Retail)

ซอร์สหลักคือ `src/retail-pos.artifact.html` (รันเป็น Claude artifact ได้ด้วย) แล้วสร้างเวอร์ชันเว็บด้วย

```
python3 tools/build_retail.py
```

ซึ่งจะเขียน `retail/index.html` โดยเพิ่มหน้าเข้าสู่ระบบ ฐานข้อมูลรายร้าน บัญชีพนักงาน และหน้าค่าบริการจาก `tools/retail-shim.html`
(ส่วนค่าบริการและที่เก็บข้อมูลดึงมาจาก `tools/standalone-shim.html` ตัวเดียวกับ Cafe) · ข้อมูลร้าน Retail อยู่ใน `pos_data` แยกตาม `shop_id` เหมือน Cafe

- ผู้จัดการร้าน = เจ้าของร้านในแอป ใช้ได้ทุกเมนู · พนักงานเข้าครั้งแรกเป็นแคชเชียร์ ผู้จัดการเปลี่ยนตำแหน่งได้ที่ ตั้งค่า › พนักงานและสิทธิ์
- SQL: `supabase/migrations/pos_retail_product.sql`
