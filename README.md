# Cafe Order + POS คาเฟ่

ระบบหน้าร้านคาเฟ่ 2 ส่วน

| โฟลเดอร์ | คืออะไร | ใช้งานที่ |
|---|---|---|
| `/` (`index.html`) | หน้าเว็บให้ลูกค้าสแกน QR สั่งอาหารจากมือถือ | https://napongbkk.github.io/cafe-order/ |
| `pos/` | ระบบ POS คาเฟ่ (หน้าขาย, โต๊ะ, จอครัว, ใบเสร็จ, รอบการขาย, รายงาน, เมนูและโปรโมชั่น, ตั้งค่า) | ใช้งานจริงผ่าน Claude Artifact |

## หมายเหตุสำคัญเรื่อง POS

`pos/index.html` เป็นซอร์สโค้ดของ POS ที่รันอยู่ใน Claude Artifact ซึ่งใช้ฐานข้อมูล ไฟล์รูป และการเชื่อม Supabase ของ Artifact
เมื่อเปิดไฟล์นี้นอก Claude (เช่นผ่าน GitHub Pages ที่ `/pos/`) ระบบจะทำงานใน **โหมดทดลอง** เท่านั้น: ใช้เมนูตัวอย่างและไม่บันทึกข้อมูลใด ๆ

## การเชื่อมต่อ

- ลูกค้าสั่งผ่านหน้าเว็บ → ออเดอร์เก็บที่ Supabase (schema `cafe`)
- เครื่องแคชเชียร์ที่ตั้งเป็น "ตัวรับออเดอร์จากแอป" ดึงออเดอร์เข้า POS ทุก 10 วินาที และส่งสถานะกลับให้ลูกค้า
- ลิงก์สั่งที่โต๊ะ: `?t=<tableId>` · สั่งกลับบ้าน: `?type=take`
