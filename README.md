# Cafe Order + POS คาเฟ่

ระบบหน้าร้านคาเฟ่ 2 ส่วน

| โฟลเดอร์ | คืออะไร | ใช้งานที่ |
|---|---|---|
| `/` (`index.html`) | หน้าเว็บให้ลูกค้าสแกน QR สั่งอาหารจากมือถือ | https://napongbkk.github.io/cafe-order/ |
| `pos/` | ระบบ POS คาเฟ่ (หน้าขาย, โต๊ะ, จอครัว, ใบเสร็จ, รอบการขาย, รายงาน, เมนูและโปรโมชั่น, ตั้งค่า) ต้องเข้าสู่ระบบ | `/pos` บน Vercel |

## POS (`/pos`)

- ข้อมูลเก็บที่ Supabase ตาราง `public.pos_docs` อัปเดตเรียลไทม์ทุกเครื่อง
- เข้าสู่ระบบด้วยอีเมล เจ้าของร้านเพิ่มพนักงานได้ที่ ตั้งค่า › พนักงาน (ตำแหน่ง: เจ้าของ / ผู้จัดการ / พนักงาน)
- รูปเมนูเก็บที่ Supabase Storage bucket `pos-menu`
- พิมพ์ใบเสร็จ/ใบสั่งครัวตรงไปที่เครื่องพิมพ์ของเบราว์เซอร์

### แก้ไข POS

ซอร์สหลักคือ `src/cafe-pos.artifact.html` (เวอร์ชันที่รันใน Claude) แล้วสร้างเวอร์ชันเว็บด้วย

```
python3 tools/build_pos.py
```

ซึ่งจะเขียน `pos/index.html` โดยเพิ่มระบบล็อกอินและฐานข้อมูลจาก `tools/standalone-shim.html`

## การเชื่อมต่อ

- ลูกค้าสั่งผ่านหน้าเว็บ → ออเดอร์เก็บที่ Supabase (schema `cafe`)
- POS ดึงออเดอร์เข้าระบบทุก 10 วินาที (มีเครื่องเดียวที่ทำหน้าที่นี้ในแต่ละช่วงเวลา) และส่งสถานะกลับให้ลูกค้า
- ลิงก์สั่งที่โต๊ะ: `?t=<tableId>` · สั่งกลับบ้าน: `?type=take`
